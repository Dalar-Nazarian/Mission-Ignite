Tech360 Basics

The perfect starting point. Learn the foundations of operating a computer, navigating the web safely, and communicating online.

Program Details:

Duration: 8 hours minimum (Best completed within a 5-day period).

Audience: Adults (18+)

Windows PC Track

  • PC Setup: Learn how to plug in and start up.
  • Windows 11: Master the operating system basics.
  • Basic Computer Skills: Mouse, keyboard, and files.
  • Internet & Email: Safe browsing and messaging.
Northstar Assessments Required: Basic Computer Skills, Windows, Internet Basics, Using Email.

Chromebook Track

  • Chrome Basics: OS navigation and device setup.
  • Basic Computer Skills: Touchpad, keyboard shortcuts.
  • Google Docs: Intro to cloud word processing.
  • Internet & Email: Safe browsing and Gmail basics.
Northstar Assessments Required: Basic Computer Skills, Internet Basics, Using Email, Google Docs.
